## 프로젝트 개요

### 1. 배경

현대 사회에서 메타버스는 단순한 가상현실을 넘어 새로운 소셜 플랫폼으로 자리잡고 있습니다. 그러나 기존 메타버스 플랫폼들은 별도의 클라이언트 설치가 필요하거나, 고사양 PC를 요구하여 진입 장벽이 높았습니다. 또한 텍스트 기반 커뮤니티의 한계를 넘어, 실제 위치 기반의 즉각적인 상호작용에 대한 니즈가 증가하고 있습니다.

이러한 배경 속에서 웹 브라우저만으로 접근 가능한 3D 소셜 메타버스 플랫폼의 필요성이 대두되었습니다. GPS 데이터와 3D 가상공간을 결합하여 현실과 가상을 연결하고, 실시간 멀티플레이어 환경에서 다양한 소셜 활동을 제공하는 통합 플랫폼을 구축하고자 합니다.

### 2. 주제

React Three.js와 Spring Boot를 활용한 위치 기반 3D 소셜 메타버스 플랫폼 구축

### 3. 목적

- **일반 사용자**: 설치 없이 웹 브라우저에서 3D 아바타로 소통하고 게임을 즐기는 경험 제공
- **커뮤니티 관리자**: 유저 활동을 모니터링하고 콘텐츠를 관리하는 운영 도구 제공
- **플랫폼 생태계**: 게시판, 상점, 미니게임 등 다양한 모듈이 유기적으로 결합된 확장 가능한 플랫폼 구축

위 세 가지를 유기적으로 연결하여 플랫폼 참여자 모두의 만족도를 높이고 새로운 소셜 경험을 창출합니다.

## 사용자별 기능 상세

### 일반 사용자 인터페이스

- **3D 가상공간 이동**: WASD 키보드 컨트롤, 걷기/달리기 모드, 물리 기반 충돌 처리
- **실시간 멀티플레이어**: WebSocket 기반 위치 동기화, 100ms 이하 지연시간 목표
- **글로벌 채팅**: 광장 전체 채팅, 캐릭터 위 말풍선 표시
- **소셜 기능**:
  · 닉네임으로 친구 요청 전송 및 수락/거절
  · 친구와 1:1 DM 채팅
  · 온라인/오프라인 상태 표시
  · 부적절한 사용자 차단 및 신고
- **미니게임 시스템**:
  · 게임별 방 목록 실시간 업데이트
  · 방 생성 (게임 선택, 인원 설정, 비공개 옵션)
  · 대기방 채팅 및 Ready 상태 토글
  · 친구 초대 기능
- **경제 시스템**:
  · 은화: 출석 보상, 게임 보상으로 획득
  · 금화: 토스페이먼츠 실결제로 충전
  · 상점에서 아바타, 악세서리, 이모트, 이펙트 아이템 구매
  · 인벤토리에서 아이템 착용/해제

### 관리자 대시보드

- **실시간 모니터링**: 접속자 수, 신규 가입, 매출 통계 시각화
- **사용자 관리**: 검색, 필터, 상세 조회, 역할 변경 (USER ↔ DEVELOPER)
- **제재 시스템**: 일시 정지 (기간 설정), 영구 정지, 제재 이력 조회
- **콘텐츠 관리**: 게시글 삭제, 채팅 로그 조회/삭제/복구
- **결제 관리**: 결제 내역 조회, 취소/환불 처리
- **감사 로그**: 관리자 활동 기록 추적

## 플랫폼 아키텍처 및 서비스 구성 계획

### 아키텍처 구성 계획

- **Frontend**: React 19, JavaScript, Three.js (3D 렌더링)
- **3D Engine**: React Three Fiber + Drei (React 환경 최적화)
- **Physics**: React Three Rapier (Wasm 기반 물리 연산)
- **Maps**: Mapbox GL (GPS 좌표 연동)
- **Backend**: Spring Boot 3.2.0 (Java 17)
- **Database**: PostgreSQL (Supabase 호스팅)
- **Authentication**: Spring Security + JWT (Stateless 인증)
- **Real-time**: Spring WebSocket + STOMP (실시간 통신)
- **Payment**: Toss Payments API (결제 게이트웨이)

### 데이터 무결성 및 보안

- JWT 토큰 기반 무상태 인증 (24시간 유효)
- 역할 기반 접근 제어 (ROLE_USER, ROLE_DEVELOPER)
- 결제 금액 서버 사이드 이중 검증

### 서비스 구성도

- **Presentation Layer**: React SPA + Three.js 3D Engine
- **Business Logic Layer**: Spring Boot REST API + WebSocket Handler
- **Data Layer**: PostgreSQL (Supabase)
- **External APIs**: Mapbox (지도), Toss Payments (결제), 한국어기초사전 (끝말잇기)

### Data Flow

- 인증: Client ↔ Spring Security (JWT)
- 데이터 CRUD: Client ↔ REST API (HTTPS)
- 실시간 동기화: Client ↔ STOMP Broker (WebSocket)
- 3D 렌더링: Client-side Three.js Engine
