```mermaid
flowchart TD

    L --> M[캐릭터 스폰]
```

```mermaid
    Y -->|No| Z[로비로 복귀]
```

### 5.3 토스페이먼츠 결제 시퀀스

```mermaid

    Note right of S: orderId 생성
    DB-->>S: PaymentHistory 저장

    S-->>U: {orderId, amount, orderName}

    U->>U: 토스 결제 위젯 열기
    U->>T: 결제 정보 입력
    T-->>U: 결제 완료 (paymentKey)

    U->>S: POST /api/payment/approve
    Note right of U: {orderId, paymentKey, amount}

    S->>T: POST /v1/payments/confirm
    Note right of S: {paymentKey, orderId, amount}

    T-->>S: 승인 결과

    alt 승인 성공
        S->>DB: PaymentHistory 상태 APPROVED
        S->>DB: User.goldCoins += goldAmount
        S-->>U: {success: true, goldCoins: 100}
    else 승인 실패
```
